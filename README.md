# kekker

A simple mouse and keyboard macro recorder written in Python.

Records mouse movements, clicks, scrolling and keyboard events,
then replays them with the original timing.

## Features

- Global hotkeys for recording and playback
- Mouse and keyboard event recording
- JSON-based macro storage
- Looping playback
- Simple GUI built with PySimpleGUI

## Controls

- F12 — Start/stop recording
- F11 — Start/stop playback

## Requirements

- Python
- pynput
- PySimpleGUI
